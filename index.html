帮助

      

        📖 使用说明（30 秒上手）
        

          
    
            
  1. 先开 ComfyUI（默认 127.0.0.1:8188），面板顶部点「连接」。状态灯变绿、模型槽自动填好就说明通了（连不上可点「▶ 启动」）。
    2. 
            
  2. 在 PS 里打开一张底图（大部分功能都要底图；纯「文生图」可以不打开）。
    3. 
            
  3. 选一个工坊：✦ 二次元工坊 / 🔞 NSFW（需先同意 18+ 条款）；每个工坊里再按顶部分类（画风 / Q 版 / 背景场景 / 服装 / 画质 …）挑选。
    4. 
            
  4. 点一张功能卡 → 模式、提示词、参数自动填好，都可以再改。提示词用祈使句最稳，例如「把背景换成雨夜街道，保留人物姿势」。
    5. 
            
  5. 点底部「生成」。出图后自动插成新图层，原图不动；也可以在「结果」里点「新文档」。
    6. 
            
  6. 不满意：点 🎲 换种子 / 参考分辨率升一档 / 把要求写得更具体。想一键出图就勾卡片上的「选完直接生成」。
    7. 
          

          
三个小技巧

          
    
            
  • 指令式写法比形容词堆叠准：「把 A 换成 B，保留脸和姿势」。
    • 
            
  • 局部重绘先用选框圈住要改的地方：Qwen 看不到选区，面板会把选区位置和占比自动补进提示词，合成时再用图层蒙版隔离（边缘按画布大小自动羽化）。
    • 
            
  • 「🧷 图片融合」可以把物体图直接拖进面板，不用点选择。
    • 
          

        

      


      

        ⬇ 模型下载与安装
        

          
模型全部放在 ComfyUI 的 models\ 下；放完点面板的「↻ 重新读取模型列表」（必要时重启 ComfyUI）。文件名不用改，放进对应目录就会被识别。

          

            
用途放哪文件名示例 / 说明

            
主模型（Qwen）models\diffusion_models\qwen-image-2.1-int8-*.safetensors（8G 选 int8，16G+ 可 bf16）

            
文本编码器models\text_encoders\qwen3vl_8b_int8-*.safetensors （别拿 32B 那个，是视频用的）

            
VAEmodels\vae\qwen_image_2.1_vae_bf16.safetensors

            
SD / SDXL（备选）models\checkpoints\sd_xl_base_1.0.safetensors

            
放大模型models\upscale_models\RealESRGAN_x4plus.pth（通用）/ _anime_6B.pth（二次元）

            
抠图（Q 版小人）models\background_removal\birefnet.safetensors

            
LoRA（可选）models\loras\面板会自动匹配与主模型同名的 LoRA

          

          
去哪下载

          
    
            
  • Qwen-Image 2.1：HuggingFace 搜 Comfy-Org/Qwen-Image_ComfyUI（含 split_files 三件套）；量化版搜 city96 的 int8/gguf 仓库。
    • 
            
  • SD / SDXL：stabilityai/stable-diffusion-xl-base-1.0。
    • 
            
  • 放大 / 抠图：搜 RealESRGAN、BiRefNet；ComfyUI 管理器的 Model Manager 也能一键装。
    • 
            
  • 国内下载慢：可用魔搭 ModelScope，或让 ComfyUI 管理器挂镜像。
    • 
          

          
放完还是看不到？

          
    
            
  • 目录名要完全一致：Qwen 的 UNET 是 diffusion_models，不是 unet 也不是 checkpoints。
    • 
            
  • 桌面版把模型放在共享目录 ComfyUI-Shared\models，无头模式需要它挂进去（面板启动器会自动生成 extra_model_paths.yaml）。
    • 
            
  • 点「↻ 重新读取模型列表」不生效 → 重启 ComfyUI。
    • 
          

        

      


      

        🎛 显卡 / 显存 → 推荐参数
        

          
下表是「能跑稳」的经验值，点上面「按本机自动调参」会直接照这个填。核心矛盾只有一个：显存。

          

            
显存档常见显卡参考分辨率步数导出长边

            
≤6GRTX 3050 Laptop / 2060 6G / 1660Ti768201536

            
8GRTX 3060Ti / 3070 / 4060 / 4060Ti / 4070 Laptop102424–302048

            
12GRTX 3060 12G / 4070 / 4070S1280302560

            
16GRTX 4060Ti 16G / 4080 / 5070Ti1536303072

            
24G+RTX 3090 / 4090 / 5090153630–404096

          

          
本机参考：RTX 4070 Laptop 8G + Qwen-Image 2.1 int8，1024 / 24 步 ≈ 33s；1024 / 12 步 ≈ 17s。显存不够时的典型症状是生成到一半 ComfyUI 进程直接退出。

          
其它参数怎么配

          
    
            
  • CFG：Qwen-Image 固定 1（再高会糊/发灰）；SD/SDXL 用 6–7。
    • 
            
  • 负面提示词只在 CFG > 1 时起作用：Qwen 用 cfg=1，负面词不参与采样（切到 SD 架构才会生效）。预设里已经按这个前提写好，正常使用不用管它。
    • 
            
  • 采样器：Qwen 用 euler / simple；SDXL 用 dpmpp_2m / karras。
    • 
            
  • 步数：Qwen 让 24–30（低于 20 细节虚）；SD 20–28。
    • 
            
  • 重绘强度（SD 图生图/局部重绘）：想保留原图 0.35–0.5，想大改 0.6–0.75。
    • 
            
  • 羽化 / 扩展（局部重绘）：羽化 8–16、扩展 4–8，边缘才不会硬切。
    • 
            
  • 放大：目标长边尽量 ≤ 4096（8G 卡），越大越容易 OOM。
    • 
          

        

      


      

        🩺 常见现象 → 该调什么
        

          

            
现象先动这里

            
生成到一半 ComfyUI 退出 / 面板提示「进程挂了」参考分辨率降一档（1024→768）、导出长边 −512；放大目标降到 4096 内

            
出图糊、细节不够参考分辨率升一档；步数 24→30；提示词补材质/光线描述

            
一张要等太久步数降到 20–24；分辨率降一档；关掉「4×」改 2×

            
图生图和原图差太远提示词写清「保留脸/姿势/背景不变」；分辨率先降一档看构图

            
局部重绘边缘生硬羽化 8–16、扩展 4–8；提示词点明「只改选区内的 XX」

            
Q 版小人出来是白底 / 空白提示词里的「纯白背景、不要投影」别删；面板会提示「没检测到成片白底」

            
模型槽是空的 / 没有新放的模型点「↻ 重新读取模型列表」；还不行重启 ComfyUI；再检查目录名

            
连接一直「未连接」ComfyUI 没开 / 端口不是 8188 / 防火墙拦了 127.0.0.1
